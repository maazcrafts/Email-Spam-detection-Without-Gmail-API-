# 📧 Email Spam Detection Using Logistic Regression

A Machine Learning Web Application that classifies emails as **Spam** or **Not Spam** using Natural Language Processing and Logistic Regression.

## 📌 Project Overview

This project uses the `completeSpamAssassin.csv` dataset to train a machine learning model for email spam classification.

The email body is converted into numerical features using **CountVectorizer**, and a **Logistic Regression** model is trained to classify emails.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- CountVectorizer
- Logistic Regression

## 🤖 Machine Learning Algorithm

**Logistic Regression**

The model performs binary classification:

- `1` → Spam
- `0` → Not Spam
